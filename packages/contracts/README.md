# Контракты API

`openapi.yaml` — спецификация HTTP API и синхронизации.

Документы:
- `docs/API_CONTRACTS.md` — контракт endpoints и ошибок;
- `docs/SYNC_PROTOCOL.md` — операции, курсоры и конфликты.

OpenAPI является машинночитаемым представлением контракта.
При изменении API сначала обновляется решение и документы,
затем спецификация, затем клиент и сервер.

Сгенерированные клиенты появятся после стабилизации контракта.
