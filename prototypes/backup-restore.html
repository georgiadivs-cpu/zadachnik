Восстановление

Восстановление выполняется только в отдельную БД и папку. Рабочие данные не перезаписываются автоматически.

  1. Скачайте архив zadachnik-2026-11-06-0812.tar.age и ключ backup.key с офлайн-носителя.
  2. Расшифруйте: age -d -i backup.key archive.tar.age > archive.tar.
  3. Запустите ./scripts/restore-verify.sh --archive archive.tar --target zadachnik_restore.
  4. Скрипт проверит схему, количество записей и SHA-256 вложений. Только после этого — ручное переключение.
Восстановление поверх рабочей БД без свежей копии и подтверждения запрещено. Ключ backup.key нельзя хранить только на сервере.

Запуск

Вручную из приложения или CLI на сервере. Оба пути используют один процесс и один lock-файл. Расписания нет.

Ключ

Рабочий ключ age: /etc/zadachnik/backup.key, права 0600. Офлайн-копия ключа хранится отдельно; пароль от неё — в менеджере паролей.

Снимки устройств

SQLite и журнал AI; последние 3 снимка на устройство. Токены, secure storage и локальные вложения не копируются: файлы уже на сервере.

Ограничения

Один диск — не полная схема 3-2-1. Рекомендуется периодически копировать самый свежий проверенный архив на второй офлайн-носитель.
