# Acceptance Criteria — критерии приёмки

Критерии являются проверяемыми условиями.
Нельзя отмечать их выполненными без теста или демонстрации.

## 1. Платформы

- [ ] Проект собирается для Android.
- [ ] Проект собирается для iOS.
- [ ] Проект собирается для macOS.
- [ ] Проект собирается для Windows.
- [ ] Ключевые сценарии проверены на каждой целевой платформе.
- [ ] Платформенные ограничения фоновой работы задокументированы.

## 2. Offline-first

- [x] Пользователь может создать заметку без сети.
- [x] Пользователь может изменить заметку без сети.
- [x] Пользователь может создать/изменить задачу без сети.
- [ ] После перезапуска локальные изменения сохраняются.
- [x] Неудачная синхронизация не удаляет локальные изменения.
- [x] После восстановления сети изменения отправляются повторно.
- [x] Повторная отправка не создаёт дубликаты.

## 3. Notes

- [x] Создание, чтение и редактирование заметок.
- [x] Markdown сохраняется без потери содержимого.
- [ ] Категории и теги работают.
- [x] Поиск находит заметку по заголовку и содержимому.
- [ ] Связи между заметками работают.
- [ ] Импорт/экспорт Markdown проверен.
- [ ] История редакций сохраняет прошлую версию.

## 4. TODO

- [x] Одна доска поддерживает от 3 до 10 дорожек.
- [x] Порядок дорожек настраивается.
- [x] Перемещение задачи меняет её дорожку.
- [x] Перемещение фиксируется в истории.
- [x] Отмена не реализована как обычная дорожка.
- [x] Плановые и фактические даты различаются.
- [x] Самостоятельные задачи работают.
- [ ] Задачи могут ссылаться на заметки.
- [ ] Чек-лист и связанная задача обновляют состояние в обе стороны.
- [ ] Нет циклического двойного переключения.

## 5. Календарь и Гант

- [x] Календарь отображает задачи по плановым датам и напоминания.
- [ ] Временные зоны обрабатываются корректно.
- [x] Гант показывает общий список подходящих задач.
- [x] Гант поддерживает фильтры.
- [x] Плановые и фактические даты различимы.
- [x] Масштабы день/неделя/месяц работают.
- [ ] Изменение дат не приводит к случайной потере данных.

## 6. Синхронизация

- [x] Клиент регистрируется на сервере.
- [x] Операции имеют уникальные ID.
- [x] Сервер безопасно обрабатывает повторную операцию.
- [x] Курсор обновляется только после успешного применения изменений.
- [x] Удаление передаётся через tombstone.
- [ ] Сбой посередине пакета не теряет неподтверждённые операции.
- [x] Параллельное изменение одного поля обнаруживается.
- [x] Конфликт не разрешается молча.
- [ ] Проверено восстановление после длительного offline.
- [ ] Проверено одновременное изменение на двух устройствах.

## 7. Вложения

- [x] Проверяются размер и допустимый тип файла.
- [x] Недогруженный файл не отображается как готовый.
- [x] Хеш/целостность проверяются после передачи.
- [x] Повтор загрузки не создаёт дубликат.
- [x] Вложения попадают в резервную копию.

## 8. AI

- [x] AI может искать и анализировать разрешённые данные.
- [x] AI готовит предложение без применения.
- [x] Пользователь видит точный список изменений.
- [x] Без подтверждения изменения не применяются.
- [x] Отказ не меняет данные.
- [x] Действие записывается в журнал.
- [x] AI не имеет произвольного SQL/shell/file access.
- [x] Инструкции внутри заметок трактуются как недоверенное содержимое.

## 9. Безопасность и восстановление

- [ ] Секреты отсутствуют в репозитории.
- [ ] API требует аутентификацию.
- [ ] Сервер проверяет права на каждую операцию.
- [ ] БД не опубликована напрямую в интернет.
- [x] Резервная копия шифруется age.
- [x] Проверено восстановление БД и целостность вложений в архиве.
- [x] Снимки устройств шифруются и не содержат токены.
- [x] Старые копии удаляются только после проверки новой.
- [ ] Восстановление проверено на чистом сервере вручную.
- [x] Приложение показывает статус копии на всех рабочих экранах.
- [ ] Миграции проверены на копии данных.
- [ ] Логи не содержат токены и приватное содержимое без необходимости.

## 10. Definition of Done

Функция принимается, если:

- выполнены её критерии;
- тесты добавлены и запущены;
- ошибки и ограничения задокументированы;
- затронутая документация обновлена;
- нет известных критических дефектов;
- пользователь получил отчёт о выполненном и непроверенном.
