## Ключевое в поиске

- отдельный полноэкранный `SearchPage`;
- вход через иконку поиска в «Заметках», «Задачах», «Календаре» и «Ганте»;
- локальный поиск без сети и backend;
- поиск по заголовкам и Markdown заметок;
- поиск по названию, описанию, дорожке и категории задач;
- регистронезависимый поиск с корректной кириллицей;
- группировка «Заметки / Задачи»;
- фильтры по типу, категории и высокому приоритету;
- подсветка всех совпадений;
- переход к редактору заметки или задачи;
- лимит 100 результатов.

## Известные ограничения

- поиск сканирует локальные данные в памяти, без FTS;
- вложения, AI-поиск и внешние источники не входят;
- дорожки и напоминания показываются как метаданные задач;
- нет зависимостей задач, критического пути и ресурсов;
- даты Ганта меняются через редактор, не drag;
- Windows-сборка не проверена;
- macOS signing/notarization не настроены.
