## Ключевое в Ганте

- новые таблицы и backend-изменения не потребовались;
- источник данных — существующие задачи и дорожки;
- плановые и фактические полосы различаются визуально;
- просрочка выделяется цветом и текстовой меткой;
- масштабы: день (21 день), неделя (12 недель), месяц (12 месяцев);
- фильтры по категориям и приоритету;
- переключатель фактических полос;
- переход к задаче по нажатию на строку;
- даты меняются только через редактор задачи, без drag;
- задачи без дат и отменённые задачи не показываются.

## Известные ограничения

- нет зависимостей задач, критического пути и ресурсного планирования;
- нет drag-изменения дат непосредственно на Ганте;
- задачи без плановых/фактических дат не отображаются;
- внешние календари и повторяющиеся события не реализованы;
- системные уведомления не проверены вручную на каждом устройстве;
- Windows-сборка не проверена;
- macOS signing/notarization не настроены.
