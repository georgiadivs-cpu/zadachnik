# NEXT_STEPS — Ежедневник

**Текущий шаг:** подготовка релиза (этап 14)
**Статус:** требуются решения по macOS/Windows и план проверки
**Предыдущий шаг:** Backup/restore — завершён

## Цель

Подготовить MVP к установке на целевые устройства: подпись,
распространение, проверка на физических платформах и инструкция
развёртывания личного сервера.

## Требуется решить до реализации

- macOS: App Store с sandbox/Keychain или распространение вне App Store;
- как распространять Windows: MSIX, установщик или архив;
- нужен ли CI и на какой площадке;
- какие физические Android/iOS/macOS/Windows устройства доступны;
- где хранить сертификаты и секреты подписи;
- какой формат инструкции развёртывания сервера.

## Предлагаемый объём после решения

- [ ] macOS signing, hardened runtime и notarization;
- [ ] sandbox и entitlements для Keychain/файлов, если нужен App Store;
- [ ] Windows CI и сборка установщика;
- [ ] проверка sync, уведомлений, вложений и backup на физических устройствах;
- [ ] инструкция сервера: PostgreSQL, API, VPN, `ATTACHMENTS_DIR`, `BACKUP_DIR`;
- [ ] проверка восстановления на чистом сервере;
- [ ] финальные лимиты, тексты и версия;
- [ ] чек-лист релиза.

## Не входит без отдельного решения

- публикация в магазинах;
- публичный сервер без VPN;
- платные сервисы и внешние API;
- автоматическое обновление приложения;
- телеметрия.

## Правило старта

Перед реализацией подготовить план, при необходимости HTML-прототип
изменений UI и получить решения по подписи и распространению.
