# NEXT_STEPS — Ежедневник

**Текущий шаг:** Markdown-редактор заметок (этап 6)
**Статус:** требуется план, HTML-прототип и подтверждение
**Предыдущий шаг:** клиентский sync engine `NOTE` — завершён

## Цель

Дать пользователю полноценно создавать и редактировать заметки в Markdown
с предпросмотром и сохранением без потери содержимого.

## Предлагаемый объём

- [ ] экран просмотра заметки;
- [ ] редактирование заголовка, Markdown и категории;
- [ ] предпросмотр Markdown;
- [ ] сохранение через существующий `NotesRepository`;
- [ ] сохранение при уходе с экрана и защита от потери введённого текста;
- [ ] индикатор локального/синхронизированного состояния;
- [ ] тесты репозитория и UI для сохранения и отмены.

## Не входит

- совместное редактирование;
- автоматическое слияние конфликтов;
- вложения;
- синхронизация задач и чек-листов;
- импорт/экспорт Markdown.

## Проверки

- `flutter analyze`, `flutter test`;
- сборки macOS/Android/iOS;
- Windows — отдельная платформа/CI;
- ручная проверка сохранения, предпросмотра и offline-режима.

## Правило старта

Перед реализацией подготовить план изменений и HTML-прототип:
шаг меняет пользовательский интерфейс и пользовательский путь.
