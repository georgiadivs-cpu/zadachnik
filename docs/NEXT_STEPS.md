# NEXT_STEPS — Ежедневник

**Текущий шаг:** TODO-доска (этап 7)
**Статус:** требуется план, HTML-прототип и подтверждение
**Предыдущий шаг:** Markdown-редактор заметок — завершён

## Цель

Дать пользователю одну общую TODO-доску с настраиваемыми дорожками,
перемещением задач и явным системным состоянием отмены.

## Предлагаемый объём

- [ ] модель задачи и миграция локальной схемы;
- [ ] одна доска и 3–10 настраиваемых дорожек;
- [ ] создание и редактирование задачи;
- [ ] перемещение между дорожками;
- [ ] плановые и фактические даты;
- [ ] отмена как системное состояние, не дорожка;
- [ ] связь заметки с задачей и чек-листом;
- [ ] тесты репозитория, миграции и UI.

## Не входит

- несколько досок и проекты;
- ресурсное планирование;
- автоматическая оптимизация расписания;
- синхронизация `TASK`/`LANE` на backend;
- AI-изменения задач без подтверждения.

## Проверки

- `flutter analyze`, `flutter test`;
- сборки macOS/Android/iOS;
- Windows — отдельная платформа/CI;
- ручная проверка перемещения, отмены и сохранения без сети.

## Правило старта

Перед реализацией подготовить план изменений и HTML-прототип:
шаг меняет пользовательский интерфейс и пользовательский путь.
