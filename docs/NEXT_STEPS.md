# NEXT_STEPS — Ежедневник

**Текущий шаг:** вложения (этап 11)
**Статус:** требуется решение по хранилищу, план и HTML-прототип
**Предыдущий шаг:** локальный поиск — завершён

## Цель

Добавить вложения к заметкам и задачам с проверкой файлов,
метаданными и предсказуемым поведением при отсутствии сети.

## Требуется решить до реализации

- где хранить файлы: локальная папка приложения, собственное
  файловое хранилище или S3-совместимый сервис;
- допустимые типы и лимиты размера;
- синхронизировать ли метаданные `ATTACHMENT` через backend;
- передавать ли файлы через API или отдельный канал;
- как показывать недогруженный файл и ошибку загрузки.

## Предлагаемый объём после решения

- [ ] выбор файла на четырёх платформах;
- [ ] проверка типа, размера и доступности;
- [ ] локальное хранение и метаданные;
- [ ] список и удаление вложений;
- [ ] состояния «загружается / готово / ошибка»;
- [ ] подготовка контракта `ATTACHMENT`;
- [ ] тесты метаданных, лимитов и UI.

## Не входит без отдельного решения

- публичный файловый сервер;
- S3-совместимое хранилище;
- шифрование вложений;
- превью всех типов файлов;
- поиск по содержимому вложений.

## Правило старта

Перед реализацией подготовить план, HTML-прототип и получить
решение пользователя по хранилищу и лимитам.
