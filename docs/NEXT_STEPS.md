# NEXT_STEPS — Ежедневник

**Текущий шаг:** диаграмма Ганта (этап 9)
**Статус:** требуется план, HTML-прототип и подтверждение
**Предыдущий шаг:** календарь и напоминания — завершён

## Цель

Показать задачи на простой временной шкале с плановыми и фактическими
датами, фильтрами и переходом к задаче.

## Предлагаемый объём

- [ ] общий режим Ганта;
- [ ] фильтры по категории, дорожке и приоритету;
- [ ] плановые интервалы;
- [ ] фактические даты/периоды;
- [ ] выделение просрочки;
- [ ] масштабы день / неделя / месяц;
- [ ] переход к редактированию задачи;
- [ ] тесты расчёта шкалы и widget-тесты.

## Не входит

- критический путь;
- управление ресурсами;
- автоматическая оптимизация расписания;
- зависимости между задачами;
- внешние календари.

## Проверки

- `flutter analyze`, `flutter test`;
- сборки macOS/Android/iOS;
- Windows — отдельная платформа/CI;
- ручная проверка масштабов и перехода к задаче.

## Правило старта

Перед реализацией подготовить план изменений и HTML-прототип:
шаг меняет пользовательский интерфейс и пользовательский путь.
