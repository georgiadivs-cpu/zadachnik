# NEXT_STEPS — Ежедневник

**Текущий шаг:** календарь и напоминания (этап 8)
**Статус:** требуется план, HTML-прототип и подтверждение
**Предыдущий шаг:** TODO-доска и sync `TASK`/`LANE` — завершён

## Цель

Показать задачи на календаре, дать удобную работу с плановыми датами
и напоминаниями с корректным учётом часовых поясов.

## Предлагаемый объём

- [ ] месячный календарь с задачами по плановым датам;
- [ ] переход из календаря к задаче;
- [ ] создание/редактирование дат без потери данных;
- [ ] локальные напоминания;
- [ ] корректная работа с локальной временной зоной;
- [ ] пустые состояния и состояния ошибок;
- [ ] тесты дат, переходов и напоминаний.

## Не входит

- внешние календари и CalDAV;
- отдельная сущность календарного события;
- повторяющиеся события;
- серверная доставка push-уведомлений;
- синхронизация напоминаний, если потребуется отдельный контракт.

## Проверки

- `flutter analyze`, `flutter test`;
- сборки macOS/Android/iOS;
- Windows — отдельная платформа/CI;
- ручная проверка смены дат и часового пояса.

## Правило старта

Перед реализацией подготовить план изменений и HTML-прототип:
шаг меняет пользовательский интерфейс и пользовательский путь.
