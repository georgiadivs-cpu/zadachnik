# NEXT_STEPS — Ежедневник

**Текущий шаг:** локальный поиск (этап 10)
**Статус:** требуется план, HTML-прототип и подтверждение
**Предыдущий шаг:** диаграмма Ганта — завершён

## Цель

Найти заметки, задачи, дорожки и напоминания локально, без сети,
с фильтрами и переходом к найденному объекту.

## Предлагаемый объём

- [ ] единая строка поиска;
- [ ] поиск по заголовку и содержимому заметок;
- [ ] поиск по названию, описанию и дорожке задач;
- [ ] поиск по категориям и напоминаниям;
- [ ] фильтры по типу и категории;
- [ ] подсветка совпадений;
- [ ] переход к заметке или задаче;
- [ ] пустые состояния и подсказки;
- [ ] тесты поисковых запросов и widget-тесты.

## Не входит

- серверный полнотекстовый поиск;
- поиск по вложениям;
- AI-поиск и суммаризация;
- внешние источники данных;
- сохранённые поисковые запросы.

## Проверки

- `flutter analyze`, `flutter test`;
- сборки macOS/Android/iOS;
- Windows — отдельная платформа/CI;
- ручная проверка поиска без сети.

## Правило старта

Перед реализацией подготовить план изменений и HTML-прототип:
шаг меняет пользовательский интерфейс и пользовательский путь.
