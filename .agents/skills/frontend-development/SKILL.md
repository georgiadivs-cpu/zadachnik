# Skill: Frontend Development

## Назначение

Реализовывать интерфейс с единым поведением
и платформенно уместными паттернами.

## Принципы

- UI не содержит бизнес-правила и прямой SQL.
- Использовать application/use-case слой.
- Показывать состояния loading, empty, error, offline,
  pending sync и conflict.
- Не скрывать ошибки сохранения.
- Сохранять ввод пользователя при навигации и временных сбоях.
- Обеспечивать доступность и клавиатурную навигацию.

## Основные экраны

Notes, TODO, календарь, Гант, поиск, настройки.

Точная навигация должна соответствовать утверждённой UI-спецификации.

## TODO

Дорожки — статусы.

Отмена — отдельное системное состояние.

Не вводить дублирующий статус.

Перемещение задачи должно вызывать один доменный use case
и создавать историю.

## Markdown

Редактор должен корректно сохранять содержимое,
поддерживать устойчивые ID checklist items
и визуально показывать связь с задачами.

## AI approval

До подтверждения показывать preview/diff.

Не изображать операцию выполненной, пока она не применена.

Отказ не должен менять данные.

## Проверки

Проверять адаптивность, доступность, ошибки, offline,
несохранённый ввод и поведение на desktop/mobile.
