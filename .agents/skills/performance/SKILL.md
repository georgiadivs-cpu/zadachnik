# Skill: Performance Engineering

## Назначение

Поддерживать отзывчивость приложения и масштабируемость
синхронизации без преждевременной оптимизации.

## Приоритеты

- Быстрый запуск и открытие основных экранов.
- Отзывчивый редактор Markdown.
- Эффективный поиск.
- Плавное отображение доски и Ганта.
- Пакетная синхронизация.
- Потоковая передача больших вложений.
- Ограниченное потребление памяти и батареи.

## Метод

1. Сначала измерить.
2. Определить узкое место.
3. Сформулировать целевой показатель.
4. Внести минимальное изменение.
5. Повторить измерение.
6. Проверить отсутствие регрессии.

## БД

Использовать индексы по реальным запросам,
избегать N+1, ограничивать выборки,
анализировать планы запросов.

Не вводить кэш, который создаёт второй источник истины
без необходимости.

## Sync

Использовать cursor-based incremental sync
и ограниченные пакеты.

Не загружать весь набор данных при каждом запуске.

Повторные запросы должны быть идемпотентными.

## UI

Не выполнять тяжёлые операции в UI-потоке.

Использовать виртуализацию больших списков,
если измерения подтверждают необходимость.

## Ограничение

Не жертвовать целостностью данных, безопасностью
или понятностью ради микропроизводительности.
